# 六种旅行图片提示词配方

先填写“源照片契约”，再选择一个配方。不要把多个风格混在一次生成里。

## 变量

- `{主体锚点}`：身份、数量、发型/轮廓、服装主色、姿势、朝向和动作。
- `{地点锚点}`：最值得留下的 1–3 个建筑、地形、植物、道路或水岸关系。
- `{构图锚点}`：观察视角、主体落点、前后关系和遮挡。
- `{色彩锚点}`：从原图提取的 2–5 种颜色。
- `{精确文字}`：用户确认的地点、年份或短标题；未确认时删除文字模块。

每段末尾都追加：

```text
上传照片是唯一事实来源。严格保留{主体锚点}、{构图锚点}与{地点锚点}。不要增减主体，不换脸，不改变姿势、朝向、视线、左右位置、前后关系、观察视角和透视。允许为版式自然裁切或横向延展背景，但不得拉伸主体、裁掉关键部位或虚构无关场景。无水印、Logo、乱码和无关文字。
```

## 01｜拼豆小分身 · `perler-companion`

```text
为这张旅行照片生成一张 4:5 或 3:4 竖版图片。保留真实照片作为主画面，在右下角或侧边加入一个小型拼豆风格的像素分身，分身高度不超过画面约 30%，不要遮挡真人、地标和关键动作。拼豆角色只提取{主体锚点}中的发型、服装主色、姿势和心情，不要把整张照片像素化。颗粒必须像真实圆柱拼豆，颜色有限，边缘有白色外轮廓和轻微手工不齐。真人和拼豆角色处于同一旅行现场，拼豆是陪伴者，不是主体替换。不要卡通大头、塑料 3D、过大角色、品牌 Logo、文字和水印。
```

## 02｜极简旅行手帐 · `minimal-sketchbook`

```text
把照片压缩成一张 1:1 极简旅行手帐绘本插画。暖白纸页占据大部分画面，主体位于中央偏下且明显缩小，上方和两侧保留大面积留白。人物只用{主体锚点}中的发型、服装主色、轮廓和姿态保持辨识度，五官极少；背景只保留{地点锚点}，其余主动删除。使用细、轻、略抖动且断续的黑色钢笔线，配合{色彩锚点}中的 2–4 种不规则淡彩平涂和粗糙干刷。无文字，避免精致人像、完整重绘、写实水彩、儿童卡通和照片转手绘滤镜。
```

## 03｜水彩票根明信片 · `watercolor-ticket`

```text
把照片重新组织成一张 4:3 横版水彩旅行票根。整张票体居中悬置在大面积象牙白留白中，厚实哑光水彩纸、自然齿边和短促柔和投影。票内左侧约 74% 是高明度、低至中饱和的水彩场景，保留{主体锚点}与{地点锚点}的空间关系；右侧约 26% 是克制的信息区，中间只有一条竖向点状撕票线。右侧默认无可读文字和数字，只放短线、点列和抽象符号。使用{色彩锚点}，保留纸张透白、干湿边缘和少量颜料颗粒。避免脏旧滤镜、复杂装饰、乱码、重复票体和廉价复古。
```

## 04｜选择性记忆拼贴 · `memory-scrapbook`

```text
将照片转译成一张 4:5 或 3:4 竖版选择性记忆拼贴。一个中等大小的主视觉承担核心故事，再从原图中准确选出 3–6 个大小不同的记忆碎片：优先选择动作、地标、器物、植物、纹样、材质或光影。碎片自然错落，不排成网格。使用哑光水粉、剪纸、孔版或丝网印刷色块，带厚实浅色切边、纸张颗粒和轻微套印误差；以暖白、雾蓝、灰绿为底，只让{色彩锚点}中的一个颜色作强调。至少保留约 35% 安静留白。无文字，避免商品目录感、卡通贴纸和无关碎片。
```

## 05｜流金珐琅旅行纪念物 · `enamel-souvenir`

```text
把照片提炼为一枚放在暖象牙白纸面上的 1:1 精致硬珐琅旅行冰箱贴。整张图只有一枚不规则徽章，外轮廓跟随{地点锚点}的真实走势；{主体锚点}作为小比例但可辨认的元素，不做精细人像。用简洁珐琅色块、深色金属分隔线、白色金属外描边和少量流金结构线塑造，色盘来自{色彩锚点}。珐琅表面饱满光洁但高光克制，边缘有真实厚度与圆润倒角，下方只有短促柔和投影。避免圆形纪念币、塑料 3D、廉价金边、厚重阴影、商品目录背景和复杂文字。
```

## 06｜地图微缩旅行场景 · `map-miniature`

```text
将照片做成一张 1:1 或 4:5 地图微缩旅行场景。暖象牙白纸质地图平放在桌面，让原图最重要的一条道路、水岸线或地形走势从平面自然生长为微缩结构，保持{地点锚点}的方向与层级；{主体锚点}变成同姿势、同朝向的小型手工模型。全景只保留一个主结构、一个主体和一个环境线索。使用真实纸张、木材、石膏和微缩模型质感，配自然光、浅景深和可信投影。地点名只有在用户确认后才能出现，否则不生成可读地名、坐标或导航数据。避免塑料玩具感、拥挤人物、错误地图文字和无关地标。
```

## 精确比例先拆后合

当用户要求原照片不被重绘、比例精确或多个元素位置固定时，不要只依赖一次整图生成：先生成拼豆角色、票根或其他衍生元素，再用确定性排版工具按坐标合成。生成模型输出即使“看起来接近”，也要按像素、主体关系、材质和文字逐项验收。
