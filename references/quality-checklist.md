# 旅行图片交付检查

在展示或保存最终图片前逐项检查。

## A. 源照片保真

- [ ] 主体身份和数量没有变化。
- [ ] 姿势、朝向、动作、视线与互动关系一致。
- [ ] 左右位置、前后关系、遮挡、视角和透视一致。
- [ ] 人物没有被过度美化，衣服、发型与代表色仍可辨认。
- [ ] 没有虚构人物、地标、天气或故事。

## B. 地点提炼

- [ ] 只留下 1–3 个地点锚点。
- [ ] 锚点足以唤起原场景，但没有完整复制复杂背景。
- [ ] 不确定的地点名、年份和坐标已省略或向用户确认。

## C. 版式与材质

- [ ] 像素宽高符合目标比例，主体没有被拉伸。
- [ ] 分区比例、主体占比与留白符合所选模式。
- [ ] 要求原照不变时，摄影区域使用原文件或等比例裁切，而不是相似的重新生成画面。
- [ ] 票根比例、主体落点和拼豆角色大小已按用户要求检查，不能只凭“看起来差不多”通过。
- [ ] 材质具有真实的不完美：纸纤维、缺墨、干刷、颗粒、倒角或投影。
- [ ] 没有平滑矢量滤镜感、塑料感或模板化装饰。

## D. 文字与洁净度

- [ ] 文字逐字准确、数量克制、层级清楚。
- [ ] 没有乱码、假坐标、假编号、品牌、签名或水印。
- [ ] 多张照片是一图一文件，没有意外拼图。

## 修正策略

只修最小失败项：

- 人脸或姿势错：强调对应源照片锚点，删掉次要装饰。
- 版式首次轻微偏差：重申精确比例、分区和主体占比，不重写风格。
- 版式再次偏差或原照被重绘：停止整图生成，改为单独生成衍生元素后确定性合成。
- 拼豆角色过大或遮挡主体：只缩小并移动拼豆角色，不重绘真人和地点。
- 材质太数字：加入可观察的物理缺陷，删掉“精致、8K、超清”等空泛词。
- 文字错：缩短文字并逐字引用；仍不稳定时移除文字。
- 背景太满：明确删除清单与留白比例，只保留 1–3 个地点锚点。
