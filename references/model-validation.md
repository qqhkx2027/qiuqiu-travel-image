# 六种模式的验证记录

## 2026-09-05｜威海 · 2024 案例

源照片是威海海边的巨型手持框景：蓝色海天、广场、人像和双手在脸旁的爱心手势。案例逐张检查后，保留以下六种模式作为公开 Skill 的核心范围。

| 模式 | 结果 | 验证重点 |
| --- | --- | --- |
| `perler-companion` | 通过视觉检查 | 真人和威海现场保持主叙事，拼豆角色位于右下角且不遮挡主体；拼豆颗粒和白色外轮廓清楚。 |
| `minimal-sketchbook` | 通过 | 人物缩小、暖白留白充分，框景、海面和爱心手势仍可辨认。 |
| `watercolor-ticket` | 通过 | 只有一张横向票体；左侧场景、右侧票根和分隔结构清楚，没有重复主体或乱码。 |
| `memory-scrapbook` | 通过 | 一个主视觉配六枚不同尺度的记忆贴纸，避免六宫格和商品目录感。 |
| `enamel-souvenir` | 通过 | 框景和双手形成徽章外轮廓，人物保持为场景中的核心元素，没有商品图背景。 |
| `map-miniature` | 通过 | 框景、双手、海岸线和人物被压缩为纸上低浮雕，地图线条没有变成错误导航信息。 |

## 已确认的修正策略

- 拼豆角色过大：缩小角色并移到边角，不能用新背景遮盖真人或地标。
- 人物不像或姿势错：删掉装饰词，重复主体身份、姿态、方向与服装锚点。
- 画面太满：减少地点锚点，明确留白比例和删除清单。
- 材质太数字：加入一种可见工艺缺陷，不同时增加五种材质。
- 文字出错：缩短并逐字引用；仍出错就删掉文字。
- 原照片被重绘或精确排版漂移：停止整图重试，改为“生成衍生元素 + 确定性合成”。
- 模式验收以“人物关系、地点锚点、比例、材质、文字、洁净度”为顺序，不被局部好看的装饰带偏。
