# qiuqiu-travel-image

**把旅行照片，变成一件可收藏的视觉记忆。**

人物、动作、视角与空间关系先被牢牢守住；会变化的，只是纸张、油墨、珐琅与场景的表达。

风格化开始之前，先回答三个问题：

- 谁是这张照片真正的主体？
- 哪个场景元素能让这段旅途立刻被认出？
- 如果只能保留一个瞬间，保留什么？

## 它解决什么

旅行照片做风格化时，最容易丢掉的不是像素，而是关系。这套 Skill 会先锁住这些事实，再进入生成：

- 人是不是同一个人，主体数量有没有变化；
- 动作、视线、朝向与人物关系有没有变化；
- 地标、地形和人物谁在前、谁在后；
- 哪 1–3 个场景元素真正定义了地点；
- 地点、年份与文字是否经确认并逐字准确。

当任务要求原图不变、比例精确或元素位置固定时，Skill 会把「生成材质」与「确定性排版」拆开处理，避免看起来相似却结构错误的成品。

## 六种风格速查

| 风格 | 模式 ID | 默认比例 | 适合的照片 |
| --- | --- | --- | --- |
| 拼豆小分身 | `perler-companion` | 4:5 / 3:4 | 想保留真实照片，再添一个像素版的自己 |
| 极简旅行手帐 | `minimal-sketchbook` | 1:1 | 有明确动作或地标，适合做减法与留白 |
| 水彩旅行票根 | `watercolor-ticket` | 4:3 横版 | 风景与人物关系清楚，适合做成可寄出的卡片 |
| 选择性记忆拼贴 | `memory-scrapbook` | 4:5 / 3:4 | 有几个值得单独记住的动作、纹样或材质细节 |
| 流金珐琅纪念物 | `enamel-souvenir` | 1:1 | 外轮廓、地标或姿态足够鲜明，适合做收藏物 |
| 地图微缩场景 | `map-miniature` | 1:1 / 4:5 | 道路、水岸、地形或建筑走势是叙事重点 |

每次只选一种主风格。若没有明确偏好，可以让 Skill 推荐不超过三种，并说明取舍。

## 安装与调用

### 1. 先看你的 AI 工具支持什么

这个仓库是平台无关的 Markdown Skill 包，不绑定某一个模型或应用。只要你的 AI 工作台或 Agent 工具支持下面任一方式，就可以使用：

| 平台能力 | 安装方式 |
| --- | --- |
| GitHub / URL 导入 | 直接导入 `https://github.com/qqhkx2027/qiuqiu-travel-image` |
| 用户级或项目级 Skills 目录 | 下载仓库后，把整个目录放进平台对应的 Skills 目录 |
| 读取本地 Markdown 指令 | 打开 `SKILL.md`，让 AI 按工作流执行 |
| 暂不支持原生 Skill | 复制 `references/prompt-recipes.md` 中对应风格的提示词使用 |

通用下载方式：

```bash
git clone https://github.com/qqhkx2027/qiuqiu-travel-image.git
```

之后请按照你所用平台的官方目录规则放置。用户级目录适合多个项目复用，项目级目录适合只在当前项目使用；不同平台的目录名称可能不同，不要直接照抄其他平台的路径。

以 Codex 为例，用户级安装路径通常是：

```bash
mkdir -p ~/.codex/skills
git clone https://github.com/qqhkx2027/qiuqiu-travel-image.git ~/.codex/skills/qiuqiu-travel-image
```

Codex 只是一个示例。其他 AI 工作台或 Agent 工具，请使用自己的 Skill 导入入口或 Skills 目录。

也可以把下面这段话交给支持 Skill 安装的智能体：

```text
请安装或导入这个旅行图片 Skill：
https://github.com/qqhkx2027/qiuqiu-travel-image

安装完成后告诉我安装位置，并检查 qiuqiu-travel-image 是否能被识别。
```

### 2. 调用

直接上传旅行照片，再说清想保留什么。

```text
请使用 qiuqiu-travel-image，把我上传的每张旅行照片分别做成极简旅行手帐。
每张独立输出，1:1，不要文字；保留人物动作与最有辨识度的地点元素。
```

```text
请使用 qiuqiu-travel-image，保留这张旅行照片的真人和地点，
在右下角加入一个小型拼豆分身。不要把整张照片像素化，
不要遮挡人物或地标，保持原来的动作、服装主色与空间关系。
```

```text
请使用 qiuqiu-travel-image，先分析这张旅行照片，推荐 3 种最合适的风格并说明理由；暂时不要出图。
```

### 3. 检查成品

先看主体和地点关系，再看材质与装饰。若身份、姿势、文字或比例不对，明确指出那一项；Skill 会优先做最小修正，而不是重新堆叠更多风格词。

## 质量边界

- 不换脸、不增人、不改变姿态、视角或空间关系。
- 地点、年份、坐标不确定时不猜；文字无法稳定生成时宁可删除。
- 不擅自拼图；系列任务默认一张照片一份文件。
- 不用「高级感」「8K」等空泛词代替纸张、油墨、水彩或珐琅的可检查材质要求。
- 可识别人像公开展示前，需要得到授权。
